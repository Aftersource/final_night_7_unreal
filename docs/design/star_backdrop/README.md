# Star backdrop references

- `star-backdrop-black.png` / `.svg`: the APPROVED look (Benito, 2026-11-14). It is generated, not a photo: a near-black sky (#000000 -> #02030c, with the faintest navy #060a24 at the bottom), ~3,800 tiny stars per 1600x900 view (a few pale blue or warm), and ~22 four-point sparkle stars with a soft glow. No moon, clouds or streaks.
- `IMG_3751.jpg`, `IMG_3755.jpg`: from Benito's style references (the same set as `docs/style-refs/`), for mood only. Their original sources are unknown; use them as reference, never as in-game art.

Chris's brief: the background plane and backdrop should be 3 to 5 layers of quick parallax, with nebula and stars for a mystical feel, discrete rather than distracting but pretty up close. Motion should be relative to the globe itself, so the star background spins as the globe moves, at the same projected rate, with the parallax configured.
